# OTT Rating Analysis Using Python

## 📌 Project Overview
This project analyzes ratings, views, genres, and OTT platforms using Python. It helps understand which OTT platform has the highest average rating, which show is most popular, and how different genres perform.

## 🎯 Objectives
- Analyze OTT show ratings.
- Compare different OTT platforms.
- Identify the highest-rated show.
- Analyze total views of each platform.
- Visualize genre distribution and ratings.

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## 📊 Dataset
The dataset contains the following columns:

| Column | Description |
|---|---|
| Platform | OTT platform name |
| Title | Show or movie title |
| Genre | Content genre |
| Rating | IMDb-style rating |
| Views | Number of views (sample data) |

## 📈 Analysis Performed
1. Average rating by OTT platform
2. Highest-rated show
3. Total views by platform
4. Genre distribution
5. Rating distribution
6. Show-wise views comparison

## 📷 Visualizations
The project generates graphs to make the analysis easier to understand:
- OTT platform rating comparison
- Genre distribution chart
- Rating histogram
- Show views comparison chart

## ▶️ How to Run the Project

1. Download or clone this repository.
2. Open Google Colab.
3. Upload the Python notebook or paste the code.
4. Run all cells.
5. View the results and graphs.

## 📌 Conclusion
This project provides a basic understanding of OTT content performance through data analysis and visualization. It demonstrates how Python libraries can be used to analyze data and extract useful insights.
